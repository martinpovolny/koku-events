Flow status

Runtime ingestion: working for fresh events

A new adapter consumer group starts at the newest Kafka offset. The request generator completed 11 creates and 12 deletes; the PoC API returned 204 and raw events rose from 1,847 to 1,942. Old records remain in Kafka under the previous group.

Metering and rated cost: not yet verified

The smoke run produced raw events, but no new metering entries or cost lines were observed. The billable-state query fix is local only; deployment awaits a decision on two old test VMs whose checkpoints would backfill about five days.

Poison batch handling: gap

An invalid or expired event can still stall an atomic adapter batch; there is no durable DLQ. Read the gap.

Catalog sync: waiting for source data

Reconciler reached OSAC without an API error. It found 0 catalog items; the PoC DB also contains 0. A non-zero end-to-end catalog sync has not yet been demonstrated.

Tenant/project endpoints unavailable
